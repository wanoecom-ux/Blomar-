# Shopify theme backups

Full copies of the Shopify theme files, taken before edits.

- `shopify-theme-pet-niche/<date_time>/` – every file of the theme
  "PET NICHE – PetLab-style layout (draft)" (theme id 154972160183) as it was in the store at that time.
- `shopify-theme-pet-niche/pre-edit/<date_time>/` – the exact files about to be changed, saved right before each edit.

To restore a file: open it here, copy its contents, and paste them into
Online Store → Themes → … → Edit code → (same file name) → Save.
